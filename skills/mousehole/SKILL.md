# 用好鼠洞

鼠洞的 MCP 服务（`mousehole`）以本人的身份使用论坛，它连上时给出的使用说明是总规矩。这里补充怎么查得准、发得好。

## 查

- 先用 `search`，关键词要短：院校、项目、方向各试一两个说法，比如"复旦 夏令营""fdu 预推免""CV 导师"。只想看标题时带 `title_only=true`。
- 保研的信息每年都变。`since=year` 只看最近一年发的，`sort=created` 按发帖时间看最新的；回答前核对帖子的日期，引用旧帖时说明是哪一年的。
- 问答帖可以带 `kind=question`、`solved=true` 只看有了答案的，`solved=false` 看还在等回答的。
- 想按版块或标签看，先 `list_boards`、`list_tags`，再用 `list_threads` 带 `board` 或 `tag`；`view=hot` 看热门，`view=unsolved` 看待解答的。
- 搜索结果只有命中的片段。要细节就用 `read_posts` 读原帖，回答前把相关的几楼读完，别只看主楼。
- 本人给的帖子链接 `https://bbs.mousebaoyan.cn/t/{id}?floor=N`，用 `read_posts` 带 `id` 和 `after=N-1` 就从第 N 楼读起。

## 答

- 把几个帖子的说法合起来答，每一条附上出处：`https://bbs.mousebaoyan.cn/t/{id}?floor={floor}`。
- 群友的说法不一致时都列出来，说清谁在什么时候说的，不替他们下结论。
- 论坛里没有的就照实说没查到，可以建议本人发帖问。

## 发

- 发帖前先搜有没有人问过；有的话建议本人去那个帖子里回复或追问。
- 求助用问答帖（`kind=question`），分享和讨论用讨论帖（`kind=discussion`）。
- 标题写成一句具体的话，比如"26 届双非软工 rk 5%，南大软院夏令营机试考什么"，不写"求助""请问"。
- 版块用 `list_boards` 里能发帖的；标签用 `list_tags` 里已有的名字，院校、方向、话题各挑最贴切的，最多 5 个。
- 正文用 Markdown。写清本人的背景（年级、学校层次、排名、方向）和想问的点，别编本人没给的信息。
- 回复时用 `reply_to_id` 指明回的是哪一层，内容要具体，不发"同问""顶"。
- 发之前把版块、标签、标题和正文完整给本人看，本人改完、同意了再发。
- 投票帖、抽奖帖、匿名和图片 Agent 发不了，请本人到网页上发。
